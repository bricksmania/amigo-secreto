Bem-vindo

Como funciona

  1. Veja a lista de nomes. Quem já escolheu aparece com ✔ já escolheu.
  2. Toque no seu nome para confirmar. Se você for responsável, sua unidade já inclui seus dependentes.
  3. Use o PIN que você criou para ver o resultado depois.
  4. Abra o link que aparece e digite o PIN para ver com quem você tirou.

Cada nome pode ser escolhido uma única vez. Ninguém consegue ver quem tirou quem, só o próprio resultado.
